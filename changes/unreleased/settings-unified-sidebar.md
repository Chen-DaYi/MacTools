Settings now combines General, About, built-in management pages, and plugin settings in one always-visible native resizable sidebar with responsive mouse and keyboard navigation. Detail pages use the toolbar title without repeating a large heading, compact descriptions and page actions scroll with their content, and Actions & Shortcuts shares the Marketplace search and filter treatment while showing each provider's icon and one settings shortcut per provider. Run Link controls now use one consistent disclosure and create a required preset immediately before the first expansion.
