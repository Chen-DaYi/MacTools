Settings now uses one always-visible resizable sidebar without a collapse control for General, About, management, and plugin pages. Its search launcher keeps the native rounded appearance, the detail header matches the content background, unified search no longer changes the sidebar viewport or scroll position while open, and toolbar navigation no longer appears above the overlay. Detail pages avoid duplicate headings, and Actions & Shortcuts uses consistent search, filters, and Run Link controls.
