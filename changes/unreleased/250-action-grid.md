Added Action Grid, a configurable, VoiceOver-accessible pointer-first launcher that centers its middle cell on the pointer when space permits, stays fully visible near screen edges, follows the pointer across multiple displays even when reusing its overlay, and supports editable 3×3 layouts, exact empty-slot placement, nested folders, and drag-and-drop ordering with a native preview, clear move-or-swap targets, and continuous placement feedback. Nested folders adapt from one to three columns and show a compact, instructive empty state instead of reserving a blank 3×3 surface. Long action names remain readable across two balanced title lines, with complete titles and availability details available from the whole cell on hover. Every tile now has one stable action name and one dedicated bottom status line: a shared primary-content anchor keeps icons and titles aligned and optically centered whether or not status is present, provider names stay in help, folders show their action count, saved scripts show their interpreter, and stateful controls show live On or Off status plus only relevant details. Actions can publish active state and a live subtitle; adaptive toggles show current state and the next operation for Keep Awake, appearance, audio mute, Night Shift, Stage Manager, automatic hiding, True Tone, Hide Notch, and Auto Input without changing the semantics of existing explicit actions. Selection, hover, active, unavailable, and running states now have distinct native treatments, concise metadata, accessible values, and properly sized failure feedback. The action picker labels adaptive actions as toggles and previews their next operation so they remain distinct from explicit On and Off actions. Action Grid refreshes only the represented stateful providers before presentation so externally changed system state is current without refreshing unrelated plugins. Its editor reliably reopens after dismissal and puts keyboard focus in action search, while shortcut presentation initially selects the center action or the closest available action. Repeated gesture and shortcut presentation safely reuses or recreates a single overlay without destabilizing application activation, and gesture release cannot click through to a newly presented cell.
