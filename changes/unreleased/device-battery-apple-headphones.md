Device Battery now uses locally advertised Apple headphone battery fields as a supplemental source when it can associate an advertisement with one unique connected target and any available product identifiers are compatible. It resolves battery percentage and charging state independently, preserves each state's actual observation time with source-specific freshness limits, and uses only a bounded recent explicit state to bridge transient Apple mobile-device read failures. It preserves more precise macOS battery levels while adding charging state, replaces a combined AirPods reading only when complete left-and-right values are available, keeps the charging case independent for split-battery models, and treats recognized AirPods Max models as single-battery headsets. Deduplication prioritizes physical identifiers exposed by system sources instead of display names alone, consolidates duplicate USB, Wi-Fi, and BLE observations through shared MobileDevice and Bluetooth identities, excludes unmatched log-only mobile records, and consolidates corroborated temporary BLE shadow records with their stable paired AirPods identity even when every component is fully charged. Both layouts use the full normalized snapshot without a fixed item-count limit, every connected supported Rapoo mouse remains visible, and opening the panel requests a throttled state revalidation. Bounded log queries, service-scoped GATT discovery, fewer layout-driven sampler restarts, and conditional broad advertisement scanning reduce avoidable background work.
