Dashboard components and Feature Panel actions can now be reordered independently. Installed plugins appear automatically on each surface they support, while the Marketplace handles installation, updates, and uninstallation; layout rows provide quick access to settings and contextual uninstall actions. The Plugins tab opens Marketplace when no installed plugin supports a layout and otherwise returns to a compatible page. Previously disabled built-in tools are restored once under the new always-available model.
