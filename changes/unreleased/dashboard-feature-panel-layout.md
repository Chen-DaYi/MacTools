Dashboard components and Feature Panel actions can now be shown or hidden independently, then reordered on each surface. The Marketplace handles installation, updates, and uninstallation; layout rows provide quick access to settings and contextual uninstall actions. Uninstall confirmations can be paused only for the current Settings session and restored from a visible banner. Existing global visibility preferences and older backups are migrated safely to both supported surfaces, while new backups preserve each surface’s separate layout and visibility.
