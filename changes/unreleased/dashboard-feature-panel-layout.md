Dashboard components and Feature Panel actions can now be shown or hidden independently, then reordered on each surface. Hiding a plugin changes only whether it appears on that surface and does not stop its background behavior; uninstall plugins you no longer want running. On first upgrade, plugins previously disabled from the Installed page will load again and remain hidden on their supported surfaces until shown, so uninstall any plugin you do not want running. The Marketplace handles installation, updates, and uninstallation; layout rows provide quick access to settings and contextual uninstall actions. Uninstall confirmations can be paused only for the current Settings session and restored from a visible banner. Existing global visibility preferences and older backups are migrated safely to both supported surfaces, while new backups preserve each surface’s separate layout and visibility.
