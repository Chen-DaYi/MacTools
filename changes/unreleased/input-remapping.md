Custom Shortcuts lets you record keyboard, mouse, scroll, and precise trackpad gestures for shortcuts, mouse navigation, and common macOS system actions in a card-based editor.

Its interface and plugin metadata are available in every language supported by MacTools.

Events generated by Custom Shortcuts always pass through, including while recording a shortcut.

Confirmed plain-key shortcuts stay enabled after restart, and conflicting precise trackpad gestures are kept exclusive across both plugins.

Trackpad Gestures now immediately removes a conflicting gesture when Custom Shortcuts already owns it.
