Added a dedicated Trackpad Gestures plugin for configurable TipTap, three- to five-finger tap, double-tap, and long-touch mappings with keyboard-shortcut and middle-click actions. TipTap actions can repeat for each additional-finger tap while the fixed fingers remain on the trackpad and consume their matching native click. Default-on, adjustable typing protection prevents palm-triggered gestures while using the keyboard. Responsive mapping controls provide one clear edit target, unique gesture choices, visible deletion, built-in TipTap and shortcut-reuse guidance, accessible labels and announcements, and a no-action test mode that stops when leaving the page. During automatic updates, affected Mouse Enhancer users receive the replacement plugin before their existing middle-click settings migrate; Mouse Enhancer then focuses on scrolling.
