Added a dedicated Trackpad Gestures plugin for configurable TipTap, three- to five-finger tap, double-tap, and long-touch mappings. A unified, searchable action picker assigns keyboard shortcuts, middle clicks, or any published MacTools action and workflow without gesture-specific modes. TipTap actions can repeat for each additional-finger tap while the fixed fingers remain on the trackpad and consume their matching native click. Default-on, adjustable typing protection prevents palm-triggered gestures while using the keyboard and now recovers automatically if macOS drops a key-up event. Action Grid launches use a trackpad-specific release guard so the opening gesture cannot click the cell that appears under the pointer. Responsive mapping controls provide one clear edit target, unique gesture choices, visible deletion, built-in TipTap and shortcut-reuse guidance, accessible labels and announcements, and a no-action test mode that stops when leaving the page. Multitouch startup and recovery remain compatible when newer macOS releases report device readiness asynchronously, including after recognition delivery, event-tap recovery, app activation, and system wake. A second MacTools process can no longer take over and stop the stable app's trackpad listener; local XCTest hosts and stale Debug copies cannot claim that listener after a test run or app restart. During automatic updates, affected Mouse Enhancer users receive the replacement plugin before their existing middle-click settings migrate; Mouse Enhancer then focuses on scrolling.
