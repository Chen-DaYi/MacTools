Added an anchored System Status overview with adjacent detail charts, plus direct First Value and optional Second Value slots that accept live values by click or drag and explain their display order. Each menu-bar metric can independently use Detailed, Compact, or Minimal style and Auto, Stacked, or Inline value layout; Auto preserves Detailed's inline values while stacking Compact and Minimal values. Full-height Compact and Minimal inline values use larger type, while Detailed retains its label-and-value hierarchy. The editor includes expanded row click targets, clearly labeled all-metric style controls, scoped reset options, and native row drag previews with insertion-gap feedback, including placement after the final metric. Battery power previews now identify charging and discharging explicitly. Charts support pinned tooltips and three time ranges.
