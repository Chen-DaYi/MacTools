Added shared actions and global shortcuts, searchable and cancellable workflows with automatic rules, visible background-run activity and diagnostics, and secure copyable Run Links. Unified Search now keeps Tab navigation contained and uses Command-Return to open the selected action’s exact editor. Preferences backups support category and per-plugin selection during both export and import, explain cross-category dependencies, and preserve workflow Run Link identities when moving workflows to another Mac.
