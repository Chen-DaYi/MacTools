Added shared actions and global shortcuts, searchable and cancellable workflows with automatic rules, visible background-run activity and diagnostics, and secure copyable Run Links. Automatic rules reject workflows that require interactive foreground actions with a specific explanation, retain external Run Link safety through nested workflows, and distinguish calendar offsets, battery thresholds, and network-interface changes without cross-firing adjacent rules. Unified Search exposes inline controls to keyboard navigation, uses Command-Return to open the selected action’s exact editor, and executes only the confirmation the user actually approved. Preferences backups support category and per-plugin selection during both export and import, explain cross-category dependencies, identify plugins referenced only by Run Links or workflows, restore configuration-defined actions on a fresh Mac, report failed provider restores without retaining dangling consumers, preserve workflow and legacy Run Link identities when moving workflows to another Mac, and exclude machine-local or sensitive action parameters even through nested workflows. Current empty shortcut backups clear imported assignments while legacy backups preserve unrelated destination shortcuts. Converged legacy shortcut bindings remain individually visible and editable, and nested Action Grid folders keep their navigation controls fully visible.
