Expanded reusable actions across Sidecar, Window Switcher, display and workspace controls, app and input controls, battery and fan controls, clipboard, disks and Trash, app repair and quitting, and physical clean mode. These actions now work consistently in shortcuts, gestures, Action Grid, Automation, and Unified Search while preserving live availability checks, confirmations, foreground-only flows, and Run Link restrictions where required.
